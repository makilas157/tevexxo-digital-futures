SPIDER MOVEMENT

When the mouse moves:

The spider should follow with a slight delay.

The body should smoothly move toward the cursor.

All 8 legs should animate independently.

The legs should bend and move naturally.

When the mouse moves fast:

The spider should crawl faster.

When the mouse stops:

The spider should slowly settle and continue a subtle idle animation.

Use spring physics.

Do not make the spider movement stiff.
